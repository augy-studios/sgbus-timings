Immigration time

This phone's calendar

Allow calendar access

Every calendar on this phone (Google, Outlook, Samsung and others), read by the app each time the Calendar tab opens. Nothing leaves the phone except each event's location, looked up to find the place.

Where to find the link
  • Google Calendar, on a computer: Settings, then your calendar under "Settings for my calendars", then Integrate calendar. Copy Secret address in iCal format.
  • Outlook: Settings, Calendar, Shared calendars. Under Publish a calendar, pick the calendar and "Can view all details", Publish, then copy the ICS link.
  • iCloud: in Calendar, share the calendar and turn on Public Calendar, then copy its link. Anyone with that link can see the calendar.

The link is kept on this device. Each time the Calendar tab opens, it's read through this site's server, because calendar services don't let a web page read it directly. The server passes the calendar straight back and keeps nothing. Treat the link like a password: anyone who has it can see your calendar.

A file is read on this device only and never sent anywhere, but it's a snapshot: import it again for new events.
