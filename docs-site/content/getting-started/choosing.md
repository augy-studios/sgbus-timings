---
title: Web app or Telegram bot?
description: Both show the same live timings. Here is what each one is better at.
---

The web app and the Telegram bot read the same data and answer the same
questions, so you can use either, or both. Favourites are kept separately in
each, so a stop starred in the app is not starred in the bot.

## Side by side

| | Web app | Telegram bot |
|---|---|---|
| Live timings at a stop | Yes | Yes |
| Search by name, code, road or postal code | Yes | Yes |
| Stops near your location | Yes | Yes |
| A bus's whole route, and the stops still ahead | Yes | Yes |
| Plan a route, with up to three changes | Yes | Yes |
| Favourite stops, buses and routes | Yes | Yes |
| Directions to a stop in Google Maps or Citymapper | Yes | Yes |
| Today's first and last bus at a stop | Yes | Yes |
| Works offline (without live timings) | Yes, once installed | No |
| Train disruptions and traffic incidents | Yes, with [service alerts](../web/service-alerts.md) | Yes, with [Service Alerts](../bot/service-alerts.md) |
| Notified of disruptions as they happen | Yes, as phone or computer notifications | Yes, as messages |
| Timings sent to you on a schedule | No | Yes, with [routines](../bot/routines.md) |
| Use it from inside another chat | No | Yes, with [inline mode](../bot/inline.md) |
| Birthday greeting | Yes | Yes |
| Copy favourites to another device | Yes, with [sync](../web/sync.md) | Not needed: Telegram is the same on every device |

## Pick the web app if

- You want to see a lot at once: every service at a stop, the incoming buses
  bar, and a route on one screen.
- You want to compare journeys on a bigger screen, with every leg's timings
  laid out at once.
- You would rather not sign in to anything. The app keeps everything in your
  browser.

## Pick the Telegram bot if

- You already have Telegram open all day.
- You catch the same bus at the same time most days, and want its timings to
  arrive by themselves. That is a [routine](../bot/routines.md).
- You want your favourites on every device you use Telegram on, without
  syncing anything.
- You want [Service Alerts](../bot/service-alerts.md) on an iPhone without
  adding the web app to your Home Screen first.
