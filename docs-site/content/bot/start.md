The bot is called **Singapore Bus Timings**, and its username is
[@UwUsgbus_bot](https://t.me/UwUsgbus_bot). It works in every Telegram app:
phone, desktop and web.

## Open it

1. Open [t.me/UwUsgbus_bot](https://t.me/UwUsgbus_bot), or search for
   `UwUsgbus_bot` in Telegram.
2. Tap **Start** at the bottom of the chat.
3. The bot replies with what it can do, every command, and buttons to open the
   web app, open this guide, or make a donation.

Send `/start` at any time to see that message again.

## Your first timings

You do not need a command to look a stop up. Just send one of these as a
message:

| Send | Example | You get |
|---|---|---|
| A 5-digit stop code | `84009` | That stop's live timings |
| Part of a stop's name or road | `bedok` | A list of matching stops to tap |
| A bus number | `22`, `971E`, `NR7` | Every stop on that bus's route |
| A 6-digit postal code | `519599` | The stops nearest that address |
| Your location | Attach, then Location | The stops nearest you |

The timings arrive as a message with buttons under it. Tap **Refresh** to bring
them up to date, and **Add favourite** to save the stop. Read on in
[Timings and their buttons](timings.md).

> [!TIP]
> Forgotten a command? Send `/start` for the list, or see the
> [Command reference](commands.md). Tapping a command in a bot's message sends
> it, so you rarely need to type one.

## Rich messages

Timings come as proper headings and tables. That needs a recent version of
Telegram. On an older app you get the same information as plain text instead;
updating Telegram brings the tables back.
