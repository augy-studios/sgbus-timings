Search suggestions open with a click again in the desktop app, a station's Train times among them, and the Train times row is spaced out.

## Download

| Device | File |
|---|---|
| Windows 10 or 11 | `sg-bus-timings-2.7.1-setup.exe` (or the `.msi`) |
| Mac with Apple silicon, or Intel | `sg-bus-timings-2.7.1-mac-arm64.dmg`, or `-mac-x64.dmg` |
| Debian, Ubuntu, Mint; Fedora, openSUSE, RHEL | the `.deb`; the `.rpm` |
| Any other Linux (with GTK 3 and WebKitGTK 4.1) | the `.AppImage` |
| Linux command line | `sg-bus-timings-cli-2.7.1-all.deb`, or `sgbus` |

The Linux files need Ubuntu 22.04, Debian 12 or newer.

This update is for the desktop app. The Android app and its watch app stay on 2.7.0, from that release.

The desktop files join the release a few minutes after it's out. Windows SmartScreen: More info > Run anyway. macOS, the first time: System Settings > Privacy & Security > Open Anyway.

## Updating

**Windows (`.exe`), Mac and AppImage**: the app updates itself. **Windows (`.msi`), `.deb` and `.rpm`**: a notification says 2.7.1 is out; install the new one over the old one. Your favourites and settings stay.

## What's new

### Desktop app
- **Search suggestions open with a click**: in Bus timings' search, clicking a suggestion did nothing, as the list closed when the mouse button went down. A station's Train times, a stop, a bus, a postal code and a recent search now open when clicked.
- **Train times spaced out**: the Train times suggestion has a gap between its label and Next trains at the station, rather than running them together.

### Linux command line
- No changes of its own: numbered 2.7.1 to stay in step with the desktop app.
